## Getting Started

### 1. Clone the repository

To get started, first clone the repository to your local machine:

```bash
git clone https://github.com/ralzina/Health_Equity_DataChallenge.git
```
### 2. Install Dependencies

Simply run

```bash
make install
```
### 3. Running the Code

Once the repository is cloned and dependencies are installed, you can run the code by using make:

```bash
make
```
